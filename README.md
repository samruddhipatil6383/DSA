DSA Practicals using C :
This repository contains my Data Structures and Algorithms (DSA) practical programs written in C. It includes different searching and sorting algorithms, stack and queue operations, recursion, and linked list implementation.

Practicals Include :
1. Linear Search
2. Binary Search
3. Bubble Sort, Selection Sort and Insertion Sort
4. Heap Sort and Basic Heap Operations
5. Fibonacci Series using Recursion and Iteration
6. Stack Implementation using Array and Linked List
7. Infix to Postfix Conversion and Postfix Evaluation
8. Queue Implementation for Task Scheduling
9. Circular Queue and Deque
10. Singly Linked List Operations
11. Quick Sort and Merge Sort

Programs :
1. linear_search.c= Searches for an element using linear search. 
2. binary_search.c= Searches for an element in a sorted array. 
3. sorting_comparison.c= Implements and compares three basic sorting algorithms. 
4. heap_sort.c= Implements heap operations and heap sort. 
5. fibonacci.c= Generates the Fibonacci series using recursion and iteration. 
6. stack_array.c= Implements stack operations using an array. 
7. stack_linked_list.c= Implements stack operations using a linked list. 
8. infix_postfix.c= Converts infix expressions to postfix and evaluates them. 
9. task_queue.c= Implements a queue for task scheduling. 
10. circular_queue.c= Implements circular queue operations. 
11. deque.c= Implements insertion and deletion at both ends of a deque. 
12. singly_linked_list.c= Implements insertion, deletion, searching and traversal. 
13. quick_merge_sort.c= Implements Quick Sort and Merge Sort and compares their execution times. 

Concepts Covered :
- Searching and sorting techniques
- Time complexity analysis
- Recursion and iteration
- Stack and queue operations
- Heap and linked list
- Expression conversion and evaluation
- Basic algorithm implementation using C

These practicals helped me improve my understanding of DSA concepts and their implementation using C programming.
